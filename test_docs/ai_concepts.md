# 人工智能核心概念

## 机器学习

机器学习是人工智能的一个分支，它使计算机能够从数据中学习，而无需明确编程。

### 主要类型

1. **监督学习** - 使用标记数据训练模型
   - 分类：预测离散类别
   - 回归：预测连续值

2. **无监督学习** - 从未标记数据中发现模式
   - 聚类：将数据分组
   - 降维：减少数据维度

3. **强化学习** - 通过与环境交互学习

## 深度学习

深度学习是机器学习的一个子集，使用多层神经网络。

### 神经网络架构

- **CNN** - 卷积神经网络，用于图像处理
- **RNN** - 循环神经网络，用于序列数据
- **Transformer** - 注意力机制，用于NLP

### 大语言模型

大语言模型（LLM）是基于Transformer架构的深度学习模型，能够理解和生成人类语言。

#### 代表性模型

- GPT系列（OpenAI）
- Claude（Anthropic）
- LLaMA（Meta）
- Gemini（Google）

## 自然语言处理

NLP是AI与语言学的交叉领域，主要任务包括：

- 文本分类
- 命名实体识别
- 机器翻译
- 问答系统
- 文本生成

## RAG技术

检索增强生成（RAG）是一种将检索系统与生成模型结合的技术。

### 工作流程

1. 文档索引和向量化
2. 查询向量化
3. 相似度检索
4. 上下文增强生成

### 优势

- 减少幻觉
- 提供可溯源的答案
- 支持实时知识更新

## 向量数据库

向量数据库专门用于存储和检索高维向量，支持相似度搜索。

### 常用方案

- Pinecone
- Weaviate
- Milvus
- Chroma
- FAISS
